# ארכיטקטורת האתר

עודכן: 2026-11-01. מבוסס על סקירת הקוד של #3 ועל הודעות המיזוג #4–#6; פרטי מימוש ה-i18n טעונים עיון נוסף בקובצי main העדכניים.

## מבנה
- אתר Static Multi-Page — HTML/CSS/Vanilla JavaScript. אין עדות בריפו שנבדק ל-React, API, database או build pipeline.
- מיפוי עמודים באמצעות `body[data-page]`. הדפים טוענים `app.js` ו-`reader.js` (יש לבדוק את גרסת main העדכנית בעקבות i18n).
- `reader.js` טוען קובצי `data/name.js` דינמית, דרך תגיות script, המגדירים `window.D[name]`.
- מסלולי תוכן פנימיים משתמשים ב-hash: למשל `parasha.html#b1-14`, `shut.html#s1`, `shira.html#h1`. שינוי סדר נתונים עלול לשבור קישורים קיימים.
- חיפוש בדפדפן: נרמול ניקוד וגרשיים, אינדקס בזיכרון, סינון לפי טקסט; אין שרת חיפוש.

## מודלי נתונים שנצפו
- `D.bereshit`, `D.shemot`: מערך פרשות עם `name`, `items`, ולמאמרים `t`, `p` (פסקאות `{t,b}`). שני הקבצים הגדולים לא הוחזרו במלואם דרך המחבר בסקירה הקודמת.
- `D.shut`: תשובות `{t,p}`.
- `D.shira`: `{t,k,p}`; קטגוריות שיר, תפילה, שמחות, שבת, מעגל השנה.
- `D.featured`: `{t,par,h,x}` לקישורי מאמרי בית, סבב לפי יום.
- `D.pidx`: `{order,map}` עם ספרי תורה, פרשות ומזהי YouTube.
- `D.playlists`: קבוצות `{k,t,l:[{t,v:[{id,t}]}]}`.
- `D.thumbs`, `D.thumbs15`: מיפוי תמונות מקדימות לפי YouTube ID; חלקן data URI.
- `BOOKS` ב-`app.js`: מערך `{t,c,p,d,i,star?}`, מטבע ₪, סינון קטגוריות.
- `VIDEOS` ב-`app.js`: מערך חדשניים `{id,d,k,t,s}`.

## UX ומיתוג
- צבעי CSS: כחול `#10285c`, זהב `#c8a24b`, שנהב `#f8f2e4`, טרקוטה `#b5532f`.
- גופנים: `Heebo` לטקסט ו-`Frank Ruhl Libre` לכותרות/תוכן תורני.
- הקוד המקורי בעברית `lang=he dir=rtl`. PR #4 הוסיף מעבר HE/EN/FR, PR #5 החליף כפתורי שפות לבורר דגלים ותיקן overflow במובייל, PR #6 תיקן cascade כיווניות, nav wrapping וייצוג דגלים.
- יש לתחזק תרגום ה-UI מול עברית כמקור אמת; מאמרי התורה עצמם אינם בהכרח מתורגמים.

## אינטגרציות
- קישורי YouTube/ערוץ `@masilatysarim`, נגן modal באמצעות `youtube-nocookie.com` עם fallback לקישור YouTube.
- Google Fonts, Open Graph, Twitter Cards, sitemap.
- טפסים: JS `preventDefault` ואישור מקומי בלבד; אין שליחה אמיתית, מסד נתונים, דיוור או תשלום. לטפסי פניות דרושים הרשאות, אנטי-ספאם, מדיניות פרטיות ובקרת תוכן.

## בדיקות מומלצות
- טעינת כל תשעת דפי ה-HTML, קישורים ותמונות ללא שגיאות console.
- ניווט ו-hash routes למאמרים, סינון, חיפוש, טקסט גדול/קטן, הדפסה ושיתוף.
- עברית/אנגלית/צרפתית: תפריט, פוטר, טפסים, LTR/RTL, מובייל וגדלי 320–1024px.
- וידאו: מודל, חסימת embed, טעינת thumbnails ומצב ללא נתוני רשת.
- SEO: canonical, robots, sitemap, preview ותאימות לתוכן האמיתי.

## שכבת ממשק רב־לשונית — תוספות PR #9 (ממתין למיזוג)
- `data/i18n.js` מכיל `window.SITE_UI_LABELS`, `window.SITE_PORTION_NAMES`, `window.SITE_BOOK_NAMES` ו־`window.siteUi/sitePortion/siteBook`. המילונים מיועדים **לממשק ולתוכן עריכתי באתר בלבד**, לא ליצירות הרב.
- `app.js` מגדיר `site-language-changed` בעת החלפת שפה. רכיבים שנבנים ב־JavaScript (`reader.js`, ספרים, סרטונים, לוח שיעורים) מקשיבים לאירוע ומציירים מחדש את תוויות הממשק.
- `reader.js` שומר את הטקסט המקורי של הרב ואת מזהי הקישורים/האינדקס, ומבדיל בין תוויות חיפוש/פרשות/קטגוריות לבין `it.t` ו־`it.p`. טקסט הרב מקבל `lang=he, dir=rtl`.
- שליחת טופסי ההדגמה מזוהה באמצעות מאזין `submit` מואצל (delegated), כי ה־HTML של הטפסים מוחלף בעת שינוי שפה. יש להחליפו בעת חיבור backend אמיתי.
- `tests/i18n-contract.test.cjs` ו־`.github/workflows/i18n-smoke.yml` מכילים בדיקות Node ללא תלויות. אין הן תחליף ל־E2E בדפדפן אמיתי.
